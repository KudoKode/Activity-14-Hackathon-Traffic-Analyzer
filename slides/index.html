NetGuard: Network Traffic Analyzer & Intrusion Detection

🚨 Problem Background

Modern campus and enterprise networks suffer from opaque traffic visibility. Cyber threats such as stealth reconnaissance port scans and distributed DoS floods blend into background web traffic, making manual packet inspection impossible without automated Layer 2–4 decoders.

Slide 2 • Architecture & Workflow

End-to-End System Architecture

⚙️ Processing Pipeline

  • Packet Ingestion: Zero-dependency binary Libpcap parser reading standard pcap captures.
  • Layer 2–4 Demuxing: Unpacks Ethernet MAC, IPv4 headers, and TCP/UDP/ICMP control flags.
  • Anomaly Engine: Real-time heuristic state machine detecting Port Scans, DoS SYN floods, and malware ports.

📊 Real-Time Analytics

  • Top Talker Matrix: Aggregates source/destination IPs by volume and packet counts.
  • Protocol Breakdown: Live percentage shares for HTTP, HTTPS, DNS, TCP, ICMP.
  • Interactive UI: Browser dashboard with Chart.js visuals and instant packet filter.
Slide 3 • Technology Stack

Under the Hood: Pure Python Architecture

🛠️ Core Engineering Stack

  • Language: Python 3.x (Clean, modular OOP design).
  • Binary Decoding: Python standard struct + socket (no Npcap/Wireshark driver locks).
  • Web Engine: Native http.server Threading API (0 pip dependencies).
  • Frontend: HTML5, CSS3 Glassmorphism, Chart.js 4.4.

⚡ Key Performance Innovations

  • Zero External Footprint: Runs out of the box on any Windows/Linux machine without installing external drivers.
  • Stream Processing: Generator-based packet iterator preventing memory exhaustion on large multi-MB captures.
Slide 4 • Security Detections & Results

Intrusion Detections in Live Evaluations

🎯 Attack Scenario Detections

  • PORT_SCAN: Flags attacker 10.0.0.99 probing 15+ destination ports during reconnaissance.
  • SYN_FLOOD_DOS: Identifies unacknowledged SYN flood from 172.16.4.88 attempting to exhaust server backlog.
  • SUSPICIOUS_PORT: Flags unauthorized connections to ports 23 (Telnet), 4444 (Metasploit), and 31337.

🛡️ False Positive Mitigation

Standard servers (DNS on 53, HTTP on 80) respond to ephemeral client ports. Our engine intelligently distinguishes server responses from outbound horizontal port scans to maintain 100% precision.
